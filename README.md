# Just Skills

발전 과제 진행에 따라 스킬을 해금하고, 사용 가능한 스킬 중 하나를 무작위로 받아 전투에 사용하는 NeoForge 모드입니다.

현재 구현에는 7개의 기본 스킬이 있으며, 모든 스킬은 짧은 시전 동작과 공통 쿨다운을 사용합니다. 각 스킬은 같은 범위 공격 계열이지만 파동, 원반, 가시, 점멸, 궤도, 균열 등 서로 다른 연출과 피해 발생 타이밍을 가집니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |
| Java | `25` |
| 발전 과제 연동 | BlazeandCave's Advancements Pack |

## 주요 기능

- 발전 과제를 조건으로 스킬 해금
- 해금된 스킬 중 하나를 무작위로 배정
- 스킬 사용 후 5분 공통 쿨다운
- `G` 키로 현재 스킬 시전
- 시전 상태를 HUD로 표시
- 이동 제한이 있는 1초 시전 방식
- 서버에서 스킬 효과와 피해 판정 처리
- 관리자용 강제 시전 명령어 제공
- 7종의 전용 파티클 연출

## 스킬 해금과 배정

현재 7개의 기본 스킬은 모두 다음 발전 과제를 해금 조건으로 사용합니다.

```text
blazeandcave:bacap/root
```

조건을 만족한 뒤 쿨다운이 끝나면 사용 가능한 스킬 중 하나가 무작위로 선택됩니다. 선택된 스킬은 HUD에서 확인할 수 있으며, 사용하면 다시 공통 쿨다운이 시작됩니다.

## 시전 규칙

모든 기본 스킬은 현재 동일한 시전 규칙을 사용합니다.

- 시전 시간: `20 ticks` = 약 1초
- 시전 중 허용 이동 거리: 시작점으로부터 최대 `1.0 block`
- 이동 제한을 초과하면 시전이 정상적으로 완료되지 않습니다.
- 실제 효과와 피해 처리는 서버에서 수행됩니다.

기본 사용 키:

```text
G
```

## 스킬 목록

현재 구현된 스킬은 다음 7종입니다.

### Crimson Wave

시전 지점을 중심으로 붉은 나선형 파동이 바깥으로 확장됩니다.

- 최대 반경: `10 blocks`
- 전개 시간: `20 ticks`
- 나선 회전: 6회
- 파동이 도달한 적대적 엔티티에 피해량 `24.0`을 한 번 적용
- 한 대상은 같은 스킬 발동에서 중복 피해를 받지 않음

### Azure Wave

푸른 고리들이 시전 지점에서 바깥으로 연속해서 퍼져 나갑니다.

- 최대 반경: `10 blocks`
- 전개 시간: `20 ticks`
- 총 20개의 확장 고리 생성
- 고리가 도달한 적대적 엔티티에 피해량 `24.0`을 한 번 적용
- 한 대상은 같은 스킬 발동에서 중복 피해를 받지 않음

### Amber Disk

호박색 입자 원반이 지면을 따라 중심에서 바깥쪽으로 채워지며 확장됩니다.

- 최대 반경: `10 blocks`
- 전개 시간: `20 ticks`
- 확장되는 원반 범위에 들어온 적대적 엔티티에 피해량 `24.0`을 한 번 적용

### Emerald Spikes

시전 지점 주변에 에메랄드빛 가시가 무작위 타이밍으로 솟아올랐다가 사라집니다.

- 최대 반경: `10 blocks`
- 가시 간격 기준: 약 `1.25 blocks`
- 가시 높이: 약 `0.8~1.6 blocks`
- 적대적 엔티티에 피해량 `24.0`을 한 번 적용
- 피해 판정 후 가시가 순차적으로 성장하고 수축하는 시각 효과가 이어짐

### Golden Flicker

시전 지점 주변에 황금빛 점들이 불규칙하게 켜지고 꺼지는 필드를 만듭니다.

- 최대 반경: `10 blocks`
- 지속 시간: `20 ticks`
- 개별 점멸 외에 순간적인 전체 암전과 플래시 효과가 섞임
- 적대적 엔티티에 피해량 `24.0`을 한 번 적용

### Indigo Orbit

남색 궤도들이 바깥쪽에서 회전하며 중심으로 빠르게 수렴합니다.

- 최대 판정 반경: `10 blocks`
- 시각 효과 시작 반경: 약 `9.5 blocks`
- 지속 시간: `20 ticks`
- 여러 회전 방향과 속도를 가진 궤도가 추가로 생성됨
- 적대적 엔티티에 피해량 `24.0`을 한 번 적용

### Violet Rift

시전 지점 주변 여러 위치에 보라색 균열이 열리고 잠시 유지된 뒤 파열합니다.

- 최대 반경: `10 blocks`
- 여러 원형 구간에 균열을 분산 생성
- 균열이 성장하고 유지된 뒤 파열 입자를 방출
- 시전 효과 초반에 적대적 엔티티에 피해량 `24.0`을 한 번 적용

> `24.0`은 모드가 피해 시스템에 전달하는 기본 피해량 값입니다. 실제 최종 체력 감소량은 Minecraft의 피해 처리 규칙과 대상 상태에 따라 달라질 수 있습니다.

## 관리자 명령어

관리자는 현재 등록된 스킬을 직접 강제 시전할 수 있습니다.

```text
/justskills cast <skill>
```

등록된 기본 스킬 ID:

```text
crimson_wave
azure_wave
amber_disk
emerald_spikes
golden_flicker
indigo_orbit
violet_rift
```

## 설치

1. Minecraft `26.1.2`와 호환되는 NeoForge를 설치합니다.
2. Just Skills JAR 파일을 서버와 클라이언트의 `mods` 폴더에 넣습니다.
3. 스킬 해금 조건을 그대로 사용할 경우 BlazeandCave's Advancements Pack을 월드에 적용합니다.
4. Minecraft를 실행합니다.

## 기술 정보

- 모드 ID: `njw_just_skills`
- 기본 스킬 해금 발전 과제: `blazeandcave:bacap/root`
- 스킬 시전과 피해 판정은 서버 권한으로 처리됩니다.
- 스킬 등록, 시전 상태, 플레이어별 스킬 상태, 전용 파티클 및 네트워크 동기화가 각각 분리되어 구현되어 있습니다.
