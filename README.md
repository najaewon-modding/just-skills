# Just Skills

발전 과제 진행에 따라 스킬을 해금하고, 사용할 수 있는 스킬 중 하나를 무작위로 받아 전투에 사용하는 NeoForge 모드입니다.

현재 7개의 스킬이 구현되어 있으며, 각 스킬은 서로 다른 범위 공격 연출을 가집니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |
| Java | `25` |
| 발전 과제 연동 | BlazeandCave's Advancements Pack |

## 주요 기능

- 발전 과제를 조건으로 스킬 해금
- 해금된 스킬 중 하나를 무작위로 배정
- 현재 스킬과 쿨다운 상태를 HUD에 표시
- `G` 키로 스킬 시전
- 스킬 사용 후 5분 공통 쿨다운
- 시전 중 일정 거리 이상 움직이면 시전 취소
- 7종의 고유한 광역 공격 스킬
- 관리자용 강제 시전 명령어 제공

## 스킬 해금과 사용

현재 기본 스킬은 BlazeandCave's Advancements Pack의 시작 발전 과제를 달성하면 사용할 수 있습니다.

쿨다운이 끝나면 해금된 스킬 가운데 하나가 무작위로 배정되며, 현재 배정된 스킬은 HUD에서 확인할 수 있습니다.

기본 사용 키:

```text
G
```

모든 기본 스킬은 약 1초의 시전 시간이 있으며, 시전 중 시작 위치에서 약 1블록 이상 벗어나면 시전이 취소됩니다.

## 스킬 목록

### Crimson Wave

플레이어를 중심으로 붉은 나선형 파동이 바깥으로 퍼져 나갑니다.

- 약 10블록 범위의 광역 공격
- 파동이 확장되며 주변 적을 공격
- 기본 피해량 24

### Azure Wave

푸른 고리 형태의 파동이 중심에서 바깥쪽으로 연속해서 퍼집니다.

- 약 10블록 범위의 광역 공격
- 여러 개의 고리가 순차적으로 확장
- 기본 피해량 24

### Amber Disk

호박색 원반이 지면을 따라 넓게 퍼지며 주변 적을 공격합니다.

- 약 10블록 범위의 광역 공격
- 중심에서 바깥쪽으로 원반이 채워지며 확장
- 기본 피해량 24

### Emerald Spikes

주변 지면에서 에메랄드빛 가시가 연속해서 솟아오릅니다.

- 약 10블록 범위의 광역 공격
- 여러 위치에서 가시가 솟았다가 사라지는 연출
- 기본 피해량 24

### Golden Flicker

주변에 황금빛 점멸 효과가 퍼지며 범위 내 적을 공격합니다.

- 약 10블록 범위의 광역 공격
- 불규칙하게 깜빡이는 황금빛 필드 생성
- 기본 피해량 24

### Indigo Orbit

남색의 원형 궤도들이 바깥쪽에서 회전하며 플레이어 쪽으로 수렴합니다.

- 약 10블록 범위의 광역 공격
- 여러 궤도가 서로 다른 방향으로 회전
- 기본 피해량 24

### Violet Rift

주변 여러 위치에 보라색 균열이 열리고 잠시 뒤 파열합니다.

- 약 10블록 범위의 광역 공격
- 여러 균열이 순차적으로 생성되어 파열
- 기본 피해량 24

> 표시된 피해량은 기본 수치이며, 실제 체력 감소량은 대상의 방어와 Minecraft의 피해 처리에 따라 달라질 수 있습니다.

## 관리자 명령어

관리자는 원하는 스킬을 직접 시전할 수 있습니다.

```text
/justskills cast <skill>
```

사용 가능한 기본 스킬 ID:

```text
crimson_wave
azure_wave
amber_disk
emerald_spikes
golden_flicker
indigo_orbit
violet_rift
```

## 설치

1. Minecraft `26.1.2`와 호환되는 NeoForge를 설치합니다.
2. Just Skills JAR 파일을 서버와 클라이언트의 `mods` 폴더에 넣습니다.
3. 기본 해금 조건을 사용할 경우 BlazeandCave's Advancements Pack을 월드에 적용합니다.
4. Minecraft를 실행합니다.
